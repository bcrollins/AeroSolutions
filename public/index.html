Getting Started

To use the AI Platform API, you'll need to:

  1. Register for an API key
  2. Include your API key in the request headers
  3. Make requests to the appropriate endpoints
// Example API request with JavaScript
fetch('/api/openai/text', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_API_KEY'
  },
  body: JSON.stringify({
    prompt: 'Hello, AI!',
    max_tokens: 50
  })
})
.then(response => response.json())
.then(data => console.log(data));

API Endpoints

Text Generation

POST /api/openai/text

Generate text responses using OpenAI's language models.

Request Body

{
  "prompt": "Write a short story about",
  "model": "gpt-4o",      // Optional
  "max_tokens": 500,      // Optional
  "temperature": 0.7      // Optional
}

Response

{
  "success": true,
  "data": {
    "text": "Once upon a time...",
    "model": "gpt-4o",
    "usage": {
      "prompt_tokens": 5,
      "completion_tokens": 100,
      "total_tokens": 105
    }
  }
}

JSON Generation

POST /api/openai/json

Generate structured JSON data using OpenAI's models.

Request Body

{
  "prompt": "Generate a list of 3 book recommendations",
  "model": "gpt-4o",      // Optional
  "max_tokens": 500,      // Optional
  "temperature": 0.7      // Optional
}

Response

{
  "success": true,
  "data": {
    "json": {
      "recommendations": [
        {
          "title": "The Great Gatsby",
          "author": "F. Scott Fitzgerald",
          "year": 1925
        },
        ...
      ]
    },
    "model": "gpt-4o",
    "usage": {
      "prompt_tokens": 8,
      "completion_tokens": 150,
      "total_tokens": 158
    }
  }
}

Image Analysis

POST /api/openai/analyze-image

Analyze images and extract information using vision models.

Request Body

{
  "image": "base64_encoded_image_data",
  "prompt": "Describe this image in detail",  // Optional
  "max_tokens": 500                           // Optional
}

Response

{
  "success": true,
  "data": {
    "analysis": "The image shows...",
    "model": "gpt-4o",
    "usage": {
      "prompt_tokens": 50,
      "completion_tokens": 200,
      "total_tokens": 250
    }
  }
}
