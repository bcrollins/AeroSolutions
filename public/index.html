API Documentation

Text Generation

Endpoint: POST /api/openai/text

Description: Generate text using OpenAI models

{
  "prompt": "Write a summary about artificial intelligence",
  "model": "gpt-4o",
  "max_tokens": 1000,
  "temperature": 0.7
}

JSON Generation

Endpoint: POST /api/openai/json

Description: Generate structured JSON data using OpenAI models

{
  "prompt": "Create a product data structure",
  "model": "gpt-4o",
  "max_tokens": 1000,
  "temperature": 0.7,
  "schema": {
    "products": [{"name": "string", "price": "number"}]
  }
}

Image Analysis

Endpoint: POST /api/openai/analyze-image

Description: Analyze images using OpenAI's vision capabilities

{
  "image_url": "https://example.com/image.jpg",
  "prompt": "Describe this image in detail",
  "model": "gpt-4o"
}
